# 🗄️ Adventure Works – SQL Analysis Project

## 📌 Project Overview

This project focuses on performing complete SQL-based data analysis using the Adventure Works dataset.
It includes data cleaning, schema corrections, KPI calculations, and generating business insights using advanced SQL queries.

---

## 🎯 Key Objectives

* Clean and prepare raw tables for analysis
* Modify data types, rename fields, and remove unnecessary columns
* Combine tables to create a unified fact table
* Calculate sales, profit, orders, and production cost
* Analyze trends by **year, month, region, and country**
* Generate top-selling products and high-profit items

---

## 🛠️ SQL Tasks Performed

* Database creation & table inspection
* Data cleaning (removing columns, fixing data types)
* Merging two fact tables using `UNION ALL`
* Adding new fields: `profit`, `year`, `month_name`, `month_number`, `quarter`
* KPI calculations:

  * Total Sales (in millions)
  * Total Profit (in millions)
  * Total Orders
* Trend Analysis:

  * Year-wise sales
  * Month-wise sales
  * Region-wise & Country-wise sales
* Top 10 highest sales orders
* Top 5 highest production cost entries
